# Blake Kenworthy — Portfolio

A responsive portfolio site for showcasing projects, skills, and freelance or internship availability.

## Run locally

Open `index.html` in a browser, or serve the repository root with any static file server. The site has no build step or runtime dependencies.

## Customize

- Update project details and links in `index.html`.
- Adjust colors, layout, and responsive styles in `styles/style.css`.
- Theme switching, mobile navigation, and project filtering are implemented in `javascript/main.js`.
- Project preview images and representative Farkle dice animations are stored in `assets/projects/`.
